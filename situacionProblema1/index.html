Input contract

Hexadecimal characters 0–9 and A–F. Line breaks are discarded, so each file becomes one continuous string.

Output contract

Implementation

C++ classes isolate each algorithm; main.cpp handles file reading and output.

Part 1 · Individual requirements

Build one string

pattern + "$" + transmission

The prefix is the pattern. A Z value tells us how many characters from this prefix match at a given position.

Recognize a hit

If Z[i] = pattern length in the transmission region, a full code occurrence begins at i − pattern length − 1 (zero-based).

Say it simply: A Z value of 3 means all three characters of A6A matched here.

Part 1 · Selection and analysis

Why choose the Z-Algorithm?

ApproachTime per searchTrade-off
Z-Algorithm · chosenO(T + M)Linear, deterministic, and simple to derive from one concatenated string.
Brute forceO(T · M)Easy to write; repeated hexadecimal characters can force many comparisons.
KMPO(T + M)Equally efficient; requires a pattern failure table.
Rabin–KarpAverage O(T + M)Hash collisions can make worst-case time O(T · M).
Aho–CorasickO(total pattern length + T + k)Scans many patterns together; extra automaton complexity is less useful for only three codes.

Cost here: O(t · m · (T + M)) time across all pairs; O(T + M + k) space per search. t = transmissions, m = mcodes, k = matches.

Part 2 · Individual requirements

Detect the longest mirror.

For each transmission, return the start and end of its longest substring that reads identically in both directions.

Chosen algorithm: Manacher’s algorithm. It handles odd and even palindrome lengths in linear time.

Illustrative input

9A6A2

The substring A6A has the same characters from left to right and right to left.

Part 2 · Visual execution

Expand once. Reuse the mirror.

Palindrome walkthrough

Illustrative input: A6A2

Known palindromeCenter or expansion

Normalize centers

A6A2 becomes |A|6|A|2|. Separators let the same radius rule cover odd and even lengths.

Reuse known work

Keep the center and right edge of the rightmost palindrome. A mirrored position gives a safe starting radius; only extend beyond known territory.

Say it simply: The algorithm avoids rechecking the part of a palindrome that its mirror already proves.

Part 3 · Individual requirements

Find the longest shared run.

Compare both transmissions and report the start and end of their longest common contiguous substring in transmission 1.

Chosen algorithm: Dynamic programming with a matrix of matching suffix lengths.

Illustrative comparison

T1: 8A6B2

T2: 7A6B9

The longest common substring is A6B, length 3.

A subsequence may skip characters; this task does not.

Part 3 · Visual execution

Matching cells extend a diagonal.

Matrix walkthrough

Rows: 8A6B2 · Columns: 7A6B9

One recurrence

match → M[i][j] = M[i−1][j−1] + 1
mismatch → M[i][j] = 0

Track the best

A cell’s value is the length of a common substring ending at those two characters. The largest value and its row identify the result in transmission 1.

Say it simply: The diagonal grows while characters agree; a mismatch resets the run to zero.

Part 3 · Selection and analysis

Clarity for one comparison.

ApproachTimeSpaceTrade-off
Dynamic programming · chosenO(T₁ · T₂)O(T₁ · T₂)Easy to inspect and verify for exactly two files.
Brute forceUp to O(T₁² · T₂²)VariesFar too many candidate substring pairs.
Suffix array + LCPO(n log n)O(n)Better scaling, more intricate construction.

Trade-off: The current matrix uses quadratic space. Two rolling rows could reduce space to O(min(T₁, T₂)) without changing the answer.

Discussion of results

What do the findings tell us?

Repeated signal

mcode3 appears every 28 characters in T2. That matches the repeated 28-character block visible in the input file.

Shared structure

Both transmissions begin with the same 28-character block. A long common substring indicates shared content, not necessarily malicious behavior on its own.

Scalability boundary

Z and Manacher scale linearly with each string. The full dynamic-programming matrix becomes the limiting step for much larger transmissions.

Conclusion: The three algorithms answer complementary questions. The current choices favor predictable searches, fast palindrome detection, and an inspectable similarity comparison. Testing also covered alternate files and empty-input edge cases.
